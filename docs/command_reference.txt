BASIC COMMANDS
--------------
help [command]          Show available commands or detailed help
  Syntax: help | help <command>
  Example: help radio | help

man <command>           Display full manual page for command
  Syntax: man <command>
  Example: man t1carrier | man emergency

events [action] [id]    View and interact with shift events
  Syntax: events | events detail <id> | events work <id>
  Example: events | events detail EV-8001

ticket <action> [args]  Trouble ticket management system
  Syntax: ticket create | ticket status | ticket <number>
  Example: ticket create | ticket T-83047

REPAIR SERVICE BUREAU
---------------------
report                  Pending customer trouble reports, nearest commitment
                        first
  Syntax: report | report show <n> | report callback <n>
          report dispatch <n> <force> | report close <n> <5|8> [fault]
          report closed | report faults | report forces
  Example: report | report show TR-04471 | report close TR-04471 5 GROUND

  A report answers to its number, to the telephone number on it, or to its
  position on the board. Disposition code 5 is trouble found and needs the
  fault named; code 8 is no trouble found. Closing a faulty line as code 8
  brings the customer back as a repeat report.

mlt <report|number>     Mechanised loop testing
  Syntax: mlt <report number | telephone number>
  Example: mlt TR-04471 | mlt 201-555-9455

  Reports insulation resistance (tip-ring, tip-ground, ring-ground), loop
  resistance, capacitance and foreign potential. Local cable is 0.083 uF to
  the mile, so capacitance on an open pair is a distance to the break.

testline [code] [ckt]   Far-end test lines and responders
  Syntax: testline | testline <code> | testline <code> <circuit>
  Example: testline 105 TG-023-BOS | testline rotl TG-001-NYC

  102-type loss; 100-type loss and noise; 105-type two-way loss, noise,
  noise with tone and gain slope; balance test line; remote office test
  line. Every loss reading is taken at 1004 Hz.

testcall <from> <to> [test line]
                        Place a test call through the network
  Syntax: testcall | testcall <from> <to> | testcall <from> <to> <test line>
  Example: testcall EO-NYC-01 EO-BOS-01 105

  Seizure removes the 2600 Hz supervisory tone toward the far end, the far
  end returns a start signal, the address goes out in multifrequency
  bracketed by KP and ST, the call advances through the hierarchy, and
  answer supervision comes back. Name a test line and the connection is
  measured rather than merely completed.

qual [index]            Craft record, qualifications and service index
  Syntax: qual | qual index
  Example: qual

  Qualification governs what you may work on. You start on Loop and Station
  plus whatever your assigned position carries, and earn the rest a
  correctly closed report at a time.

DIFFICULTY
----------
set game.difficulty fun     Fun Simulation. Close reports without measuring,
                            advance quickly, a wrong call costs little
set game.difficulty craft   I Hate Myself. Measure before you close, repeat
                            reports come back on your index, commitments are
                            counted, and qualification is slow
set game.ambience off       Silence the other craft

THE OTHER CRAFT
---------------
who                     Who is logged on, and what they do
write <user> [message]  Write to another terminal, as write(1) did
mail                    Read mail left for you
orderwire [scc|report]  The maintenance order wire to the control centre

  Traffic reaches you on four channels: write(1) interrupts your terminal,
  mail(1) waits, the order wire carries the field and the switching control
  centre, and the maintenance teletype prints CAROT's exceptions whether
  anybody is reading or not.

QUICK TIPS
----------
• Most commands accept 'status' as first argument for overview
• Use 'help <command>' for syntax and examples
• Type 'events' to see current shift activities
• Commands can be abbreviated (e.g., 'rad st' for 'radio status')
• All ticket numbers follow format: T-XXXXX, EV-XXXX
• Emergency procedures use 'emergency' command with escalation levels
