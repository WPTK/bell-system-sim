STARTING
--------
bell-system                 Start; the login prompt lists the positions with ?
bell-system --role N        Start at position N (1-12), skipping the menu
bell-system --simple        A plain Unix V7 sandbox (shell only, no board)
bell-system --version       Print the version and exit

IF YOU ARE STUCK
----------------
help                    Opens on what to do now, from your actual board
help <command>          One line on a single command
man <command>           The manual page for any command
hint                    Ask somebody. Ask again for more, three levels deep
report next             The one report that most wants working

THE REPAIR BUREAU
-----------------
The loop is four commands:

  report                          What is on your board
  mlt 1                           Measure the line
  report dispatch 1 outside       Send somebody
  report close 1 5 SHORT          Close it out

report                  The pending list, nearest commitment first
  Syntax: report | report next | report show <n> | report callback <n>
          report dispatch <n> <force> | report close <n> <5|8> [fault]
          report closed | report faults | report forces
  Example: report show TR-04471 | report close TR-04471 5 GROUND

  A report answers to its number, to the telephone number on it, or to its
  position on the board. Code 5 is trouble found and needs the fault named;
  code 8 is no trouble found. Closing a faulty line as code 8 brings the
  customer back as a repeat report.

mlt <report|number>     Mechanised loop testing
  Syntax: mlt <report number | telephone number>
  Example: mlt TR-04471 | mlt 1

  Insulation resistance on tip-ring, tip-ground and ring-ground, loop
  resistance, capacitance and foreign potential. Local cable is 0.083 uF to
  the mile, so capacitance on an open pair is a distance to the break.

testboard               The test board
  Syntax: testboard | testboard loop <report> | testboard supervision <circuit>
          testboard results | testboard status
  Example: testboard supervision TG-001-NYC

testline [code] [ckt]   Far-end test lines and responders
  Syntax: testline | testline <code> | testline <code> <circuit>
  Example: testline 105 TG-023-BOS

  102-type loss; 100-type loss and noise; 105-type two-way loss, noise,
  noise with tone and gain slope; balance test line; remote office test
  line. Every loss reading is taken at 1004 Hz.

testcall <from> <to> [test line]
                        Place a test call through the network
  Example: testcall EO-NYC-01 EO-BOS-01 105

orderwire [scc|report <text>]
                        The maintenance order wire

shift                   Where you are in the tour
handoff                 The full turnover record
handoff relieve         Sign off. The index banks, the day moves on
qual [index]            Craft record, qualifications and service index
career new [confirm]    After the last tour: file the career, start the next

DIFFICULTY AND SETTINGS
-----------------------
set                     Every setting, its value and its options
set game.difficulty fun     Fun Simulation. Loop testing names the fault for
                            the first two sightings of each kind, a wrong
                            call costs little
set game.difficulty craft   I Hate Myself. Measure before you close, repeat
                            reports come back on your index, commitments are
                            counted, and qualification is slow
set game.prompts on     Have the terminal tell you what to do next
set game.ambience off   Silence the other craft
set display.pacing off  Print at once instead of at 300 baud
set date.source real    Use your own system clock instead of 1983
set reset               Restore period-accurate defaults

QUALIFICATION
-------------
You start on Loop and Station, plus whatever your position carries. A
command you are not signed off on is refused; help marks it with an asterisk.

Loop and Station          report, mlt, trouble, testboard, testline
Main Distributing Frame   cosmos, lmos
Central Office Switching  switch, alarm, crossbar, 3a
Switching Control Center  sarts, orderwire, connect
Interoffice Trunks        trunk, routing, dialtone, testcall
Toll Network              toll, tnds, traffic

'cosmos jumper <number>' only reads a line's frame record and needs no
sign-off. The rest of cosmos, and 'cosmos fix', need the frame sign-off.
