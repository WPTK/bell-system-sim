NAME
     bell_system_unix - Bell System UNIX Version 7 Internal Operations Terminal Simulation

SYNOPSIS
     bell-system [--tutorial] [--role N] [--simple] [--version]
     python -m bell_system [--tutorial] [--role N] [--simple] [--version]

DESCRIPTION
     The Bell System UNIX V7 Terminal Simulation provides an authentic recreation 
     of AT&T Bell System internal operations workstations from 1978-1983. This 
     historically accurate simulation reproduces the experience of using original 
     UNIX V7 systems with period-accurate Bell System commands, workflows, trouble 
     tickets, and role-specific operations.

     The simulation is based on extensive Bell System Technical Journal 
     documentation, Engineering and Operations manuals, Bell System Practices 
     (BSP), and authentic AT&T internal procedures from the pre-divestiture era.

HISTORICAL CONTEXT
     This simulation represents Bell System operations during the critical period 
     of 1978-1983, when the company was transitioning from electromechanical to 
     electronic switching systems while preparing for the 1984 divestiture. The 
     simulation includes authentic equipment (3A Central Control, 5ESS, TH-3 
     microwave, TNDS), procedures, and terminology from this transformative period 
     in telecommunications history.

INSTALLATION
     Requirements:
       - Python 3.9 or higher
       - Terminal emulator supporting ANSI escape sequences
       - Unix-like operating system (Linux, macOS, BSD) or Windows with WSL

     Setup:
       1. Ensure Python 3 is installed: python3 --version
       2. Clone the repository and install it: pip install -e .
       3. Run the simulation: bell-system

USAGE
     Start the simulation with the bell-system command. You will be presented
     with a role selection menu offering 12 authentic Bell System positions.
     After selecting a role, you'll receive a shift briefing and access to
     role-appropriate commands. The --role option takes a number from 1 to 12
     and skips the menu.

     Commands are entered at the Unix-style prompt. Type 'help' for available 
     commands or 'man <command>' for detailed documentation.

     To exit the simulation, use Ctrl+C or the 'exit' command.

ROLES
     The simulation offers 12 authentic Bell System operational roles:

     1. UNIX Systems Operator
        System maintenance, UUCP operations, PWB development environment
        Tools: ps, df, who, uucp, mail, pwb, rje

     2. Switching Station Technician  
        Telephone switching equipment management and maintenance
        Tools: trunk, switch, testboard, toll, crossbar, alarm, 5ess, 3a

     3. Field Support Liaison
        Coordinate field technicians and central office operations
        Tools: trace, dialtone, emergency, ticket, provision, sarts

     4. National NOC Analyst
        Network operations and critical incident management
        Tools: trunk, emergency, switch, ticket, traffic, tnds, satellite

     5. Traffic Service Position System Operator
        Operator-assisted calls and directory assistance
        Tools: tsps, operator, directory, collect, billing

     6. Database Administrator
        Customer records and network configuration data management
        Tools: dbquery, custdb, billing, netdb, service

     7. Network Planning Engineer
        Network design and capacity planning
        Tools: netplan, traffic, routing, capacity, billing, tnds

     8. Customer Service Interface Technician
        Service orders and customer provisioning
        Tools: service, provision, billing, custdb, directory

     9. Radio/Microwave Technician
        TH-3 microwave systems and satellite communications
        Tools: radio, microwave, propagation, antenna, fade, satellite

     10. Total Network Data System (TNDS) Analyst
         Network traffic data collection and analysis
         Tools: tnds, netdata, analysis, forecast, modeling, traffic

     11. SARTS (Special Service Testing) Technician
         Remote testing of special service circuits
         Tools: sarts, remote, special, testing, circuits, provision

     12. Document Preparation Specialist
         UNIX document preparation and technical writing
         Tools: nroff, troff, tbl, eqn, pic, refer, pwb

COMMANDS
     Core Network Operations Commands:

     3a [status|diagnostics|traffic|maintenance|translations]
         3A Central Control switching system operations
         
         Examples:
           3a status        Display system configuration and performance
           3a diagnostics   Run comprehensive system diagnostic suite
           
     alarm [status|critical|acknowledge|history|escalate]
         Central office alarm monitoring and response
         
         Examples:
           alarm status     Show current alarm conditions
           alarm critical   Display critical alarms only
           
     analysis [traffic|performance|trends|capacity]
         Advanced network analysis and modeling tools
         
     billing [rates|usage|reports|international|collect]
         Customer billing and toll charge calculation
         
         Examples:
           billing rates interstate    Show interstate calling rates
           billing usage summary       Generate usage summary reports
           
     bsp [search|section|recent|index] <args>
         Bell System Practices - Standard Operating Procedures
         
         Examples:
           bsp search switching        Search for switching procedures
           bsp section 200-455-100     Display specific BSP section
           
     capacity [status|planning|utilization|forecasting|growth]
         Network capacity planning and utilization analysis
         
     circuits [test|status|repair|provision|monitor]
         Circuit management and testing operations
         
     coer [generate|faults|trends|maintenance]
         Central Office Equipment Reports - Performance monitoring
         
         Examples:
           coer generate    Generate comprehensive performance report
           coer faults      Display equipment fault analysis
           
     crossbar [status|maintenance|testing|performance]
         Crossbar switching system controls and monitoring
         
     custdb [query|update|reports|maintenance|backup]
         Customer database operations and analytics
         
     dbquery [select|update|reports|maintenance|performance]
         Database query and management operations
         
     directory [assistance|lookup|update|maintenance]
         Directory assistance services and number lookup
         
     dialtone [test|verify|troubleshoot|quality]
         Dial tone testing and verification procedures
         
     emergency [dispatch|escalate|status|procedures|recovery]
         Emergency dispatch and escalation system with disaster recovery
         
         Examples:

         Switching center management and diagnostics

ENVIRONMENT
     The simulation runs in a standard Unix terminal environment and requires
     no special configuration. All Bell System procedures and data are
     historically accurate representations based on authentic documentation.

     BELL_SYSTEM_HOME
          Directory for logs and command history. When unset, the simulation
          uses $XDG_STATE_HOME/bell-system, falling back to
          ~/.local/state/bell-system. Nothing is written to the working
          directory.
