
BELL SYSTEM UNIX/TS TROUBLESHOOTING MANUAL
=========================================
Internal AT&T Document - Proprietary
Last Updated: 1979

1. SYSTEM ALERTS AND RESOLUTION PROCEDURES
----------------------------------------

1.1 TRUNK ALERTS
Command set: trunk
  trunk status          - Display trunk line status
  trunk test <circuit>  - Run diagnostic on circuit
  trunk reset <circuit> - Reset circuit after repair
  trunk log            - View trunk error log

Standard Resolution Procedure:
1. Use 'trunk status' to identify affected circuits
2. Run 'trunk test' on problematic circuit
3. If test fails, contact field maintenance
4. After repair, use 'trunk reset'

1.2 SWITCHING MATRIX ISSUES
Command set: switch
  switch status        - Display switch matrix status
  switch sync         - Resynchronize timing
  switch drift        - Show timing drift values
  switch calibrate    - Calibrate matrix timing

Resolution for Timing Drift:
1. Check drift values with 'switch drift'
2. If >500ms, run 'switch calibrate'
3. Use 'switch sync' to realign timing
4. Monitor with 'switch status'

1.3 UUCP CONNECTIVITY
Command set: uucp
  uucp check <node>    - Test connection to remote
  uucp queue           - List pending transfers
  uucp retry <jobid>   - Retry failed transfer
  uucp clean           - Clear stale locks

When Connection Fails:
1. Use 'uucp check' to test specific node
2. Check 'uucp queue' for stuck transfers
3. Clear locks with 'uucp clean'
4. Retry failed jobs with 'uucp retry'

1.4 LOAD MANAGEMENT
Command set: load
  load show            - Display load metrics
  load kill <pid>      - Terminate process
  load nice <pid> <n>  - Adjust process priority
  load watch           - Monitor system load

High Load Resolution:
1. Use 'load show' to identify heavy processes
2. Adjust priority with 'load nice'
3. If necessary, terminate with 'load kill'
4. Monitor using 'load watch'

2. EMERGENCY PROCEDURES
----------------------
For critical system failures:
1. Contact NOC immediately via intercom (x2317)
2. Log incident in /usr/adm/errors
3. Use 'emergency halt' only as last resort
4. Maintain paper trail using 'hardcopy' command

3. MAINTENANCE SCHEDULE
----------------------
Daily:
- Check error logs: 'error log'
- Monitor trunk status: 'trunk status'
- Review UUCP queues: 'uucp queue'

Weekly:
- Full system diagnostics: 'diag full'
- Timing calibration: 'switch calibrate'
- Clean UUCP locks: 'uucp clean'

Monthly:
- Complete tape backup: 'backup full'
- Node connectivity test: 'uucp verify all'
- Performance analysis: 'perf report'
